## Uso de inteligencia artificial

Se utilizó modelos de modelos LLM como ChatGPT y Geminini asistente,mejora y ayuda para la resolución del mismo

### Prompts utilizados

- Analizar a mejorarícitos.
- Ayudar a mejorar la arquitectura AWS distribuida y tambien en calculo de costos.
- Ayudar y mejorar los Dockerfiles para una mejor performance , como tambien el file de docker Compose.
- Ayudar y asistir en la config. de un pipeline para el despliegue CICD en github.

### Herramientas y skills

- Suite de Draw io para generacion de Diagrama de Arq.
- IDE de VisualStudio para la codificacion y github como respositorio de codigo.
- Docker y Docker Compose para empaquetado y orquestación local.
- GitHub Actions y GHCR para CI/CD y registro.
